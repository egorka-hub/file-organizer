# ПОРТ — Программа Организации Разнообразных Типов

Утилита для автоматической сортировки файлов по типам в директории.

## Описание проекта

Программа сканирует указанную директорию и раскладывает файлы по подпапкам
(`Images`, `Documents`, `Music`, `Video`, `Archives`) на основе их расширения.
Все операции логируются в файл `organizer.log`, а по завершении выводится
отчёт со статистикой обработанных файлов.

## Возможности

- Автоматическая сортировка файлов по расширениям
- Логирование всех операций (создание директорий, перемещение файлов, ошибки)
- Отчёт со статистикой по каждой категории (количество файлов и суммарный размер)
- Обработка конфликтов имён — при совпадении имени файл переименовывается с добавлением временной метки

## Установка

```bash
git clone https://github.com/username/file-organizer.git
cd file-organizer
go build
```

## Запуск

```bash
./file-organizer
```

При запуске программа спросит путь к директории для организации. Если
просто нажать Enter, будет использована текущая рабочая директория.

## Примеры использования

```
$ ./file-organizer
=== Файловый органайзер ===
Введите путь к директории для организации (Enter для текущей директории): /home/user/downloads

=== Отчёт о перемещении файлов ===

Всего обработано файлов: 42
Общий размер: 128.50 KB

Статистика по категориям:

Documents:
  Файлов: 15, Размер: 45.30 KB

Images:
  Файлов: 20, Размер: 80.20 KB

Music:
  Файлов: 7, Размер: 3.00 KB

Организация завершена! Подробности в файле organizer.log
```

Пример при ошибке (несуществующая директория):

```
$ ./file-organizer
=== Файловый органайзер ===
Введите путь к директории для организации (Enter для текущей директории): /nonexistent
cannot create organizer: cannot stat sourceDir: stat /nonexistent: no such file or directory
```
